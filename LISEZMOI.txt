CROC — VARIANTE « SYSTÈME DU DÉDALE »
=====================================

La fiche de Croc telle que le Système du Dédale l'affiche, dans le même
style que le site de Varn : terminal vert phosphore sur noir, fenêtres
« SYSTÈME » à coins en équerre, glitchs, scanlines, notifications.
Aucune installation, aucun fichier son : les bruitages sont fabriqués
en direct par le navigateur.

CONTENU DU DOSSIER
- index.html, style.css, app.js : le site (ne pas renommer).
- data.js : TOUT le contenu de la fiche (textes, stats, compétences…).
- images/ : les illustrations (croc-*.jpg) et le portrait d'Eilyn.
- .nojekyll : fichier vide utile à GitHub Pages (laisse-le).
- LISEZMOI.txt : ce fichier.


METTRE EN LIGNE SUR GITHUB PAGES
1. Si tu as reçu un .zip, dézippe-le d'abord.
2. Sur github.com : bouton « + » en haut à droite > « New repository ».
   Nom : par exemple « croc-systeme » · visibilité : Public · « Create repository ».
3. Dans le dépôt vide : « Add file » > « Upload files »
   (ou le lien « uploading an existing file »).
   Glisse le CONTENU du dossier (index.html, style.css, app.js, data.js,
   LISEZMOI.txt, .nojekyll et le dossier images/), pas le dossier lui-même.
   Le fichier .nojekyll est « caché » sur certains ordinateurs : s'il
   n'apparaît pas, ce n'est pas grave, le site fonctionne sans.
4. En bas de la page : « Commit changes ».
5. Onglet « Settings » > « Pages » (menu de gauche) > « Build and deployment » :
   Source = « Deploy from a branch » · Branch = « main » · dossier « / (root) » · « Save ».
6. Attends 1 à 2 minutes puis recharge la page « Pages » : l'adresse s'affiche
   en haut, du type https://TON-PSEUDO.github.io/croc-systeme/


MODIFIER LE CONTENU (data.js)
- Sur GitHub : clique sur data.js > icône crayon (Edit) > modifie > « Commit changes ».
  Le site se met à jour en une minute environ (recharge la page, au besoin Ctrl+F5).
- Garde bien les guillemets et les virgules : chaque texte est entre '…' et suivi
  d'une virgule. Pour une apostrophe dans un texte entre '…', mets un \ devant : 'l\'arme'.
- Ce que lit chaque onglet :
  · Démarrage : boot (les lignes du Système, après « IDENTIFICATION DU SUJET… »).
  · FICHE : nom, sousTitre, champs (Espèce, Âge, Taille, Poids vont dans le panneau
    à côté de la photo, les autres dans la grille dessous), physique, titres (badges),
    frere, et la note de psycho qui parle de prudence (bloc d'avertissement rouge).
    Photo de la carte : l'image de galerie dont le nom contient « sourire » ;
    fond d'accueil : celle qui contient « couloir ».
  · PSYCHÉ : psycho (notes du Système) et frere (seule silhouette « NON-NPC » de la foule,
    avec le portrait et la note de sa fiche dans relations).
  · STATISTIQUES : stats (barres de 20 cases, « bonus » optionnel affiché en or),
    rolls (jauges sur 100).
  · COMPÉTENCES : competences (groupe 'Spéciale' ou 'Classique', niveaux, coût, préavis,
    recharge, bonus, marques, condition, spécial ; « des » = faces du dé du LV.5)
    et catastrophes (exemples tirés au hasard pendant la simulation).
  · TITRES : titres (nom, condition, effet).
  · RELATIONS : relations (un exemple à copier est en commentaire dans data.js)
    et relationsCases (nombre de cases ; les vides sont grisées).
  · ARCHIVES : galerie (chemin de l'image + description).
- Ajouter une image : « Add file » > « Upload files » dans le dossier images/,
  puis ajoute une ligne dans « galerie » : { src: 'images/mon-image.jpg', alt: 'description' },
- Le bloc « retro » à la fin de data.js sert à l'autre variante : celle-ci l'ignore.


À SAVOIR
- Écran de démarrage : « INITIALISER AVEC SON » ou « SANS SON » (Entrée / Échap au clavier).
  « PASSER › » saute la séquence. Il ne s'affiche qu'une fois par session d'onglet.
- Bouton « ♪ SON » (ou touche M) : coupe / remet le son. Le navigateur n'autorise
  le son qu'après un premier clic.
- Bouton « CRT » : coupe les effets d'écran (lignes, pluie de données, coupures de signal).
- Si ton système demande de réduire les animations, tremblements, flashs, glitchs
  et transitions sont supprimés automatiquement.
- Clavier : 1 à 7 = onglets, ? = aide, Échap = fermer une fenêtre, flèches = cibles
  (PSYCHÉ) et images (ARCHIVES). Sur ordinateur, on peut saisir l'en-tête d'une
  fenêtre « SYSTÈME » pour la déplacer (double-clic : elle reprend sa place).
- Simulations ([Lien Infortuné], [Accumulation du Chaos], jugement des NPC) :
  purement illustratives. Leurs compteurs sont gardés dans TON navigateur uniquement.
- « EXPORTER EN PNG » (onglet FICHE) : fonctionne une fois le site en ligne. Si tu
  ouvres index.html directement depuis ton ordinateur, le navigateur bloque l'export.
- Rien n'a été inventé sur Croc : nom et prénom restent « ??? ». L'identifiant
  « CRC-… », les messages du Système et les silhouettes de la foule sont de l'interface.
- Illustrations : fan arts, droits réservés à leurs auteurs. Si tu connais les artistes,
  ajoute leurs noms dans la phrase du pied de page (index.html, classe « credit »).
